# Calby Premium Alarm Sounds

Place licensed alarm audio files (.mp3 or .wav) in this directory:

- `calby-wake.mp3`    — Calby Wake (Uplifting morning alert)
- `calby-focus.mp3`   — Calby Focus (Steady focus signal)
- `calby-alert.mp3`   — Calby Alert (Clear, attentive alert)
- `calby-classic.mp3` — Calby Classic (Classic desktop chime)

## Licensing Requirements
Only place audio files here if their license explicitly permits redistribution within a desktop application.
If an audio file is absent or cannot be loaded, Calby automatically falls back to built-in procedural Web Audio tones.
