# Calby — Product Requirement Document (PRD)

## Overview

Calby is a personal desktop assistant designed to help users manage information, plans, and things they need to remember without manually managing everything.

- **Product Foundation & Principles:** See [PRODUCT_FOUNDATION.md](file:///d:/electron.js/calby/docs/product/PRODUCT_FOUNDATION.md)
- **Global Requirements:** See [GLOBAL_REQUIREMENTS.md](file:///d:/electron.js/calby/docs/product/GLOBAL_REQUIREMENTS.md)

## Core Capabilities (MVP Scope)

1. **Voice Assistant** — Voice-first interaction with natural language understanding via Gemini.
2. **Smart Reminders** — Natural-language creation, scheduling, and local management.
3. **Offline Reminders & Notifications** — Desktop notifications, native alarm overlays, and snooze/dismiss behaviors.
4. **Calendar Understanding** — Google Calendar connection and contextual schedule inspection.
5. **Personal Memory** — Store, view, edit, and clear personal user preferences and facts.
6. **Meeting Preparation** — Contextual briefing combining calendar events with relevant memory facts.
7. **Settings & Privacy Controls** — Granular user control over API connection, voice, notifications, calendar, memory, and general behavior.
8. **Desktop Experience** — System tray execution, quiet background operation, and connection error handling.
