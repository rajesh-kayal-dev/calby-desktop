# Calby Premium Notification Sounds

Place licensed notification audio files (.mp3 or .wav) in this directory:

- `calby-soft.mp3`  — Calby Soft (Gentle, soft chime)
- `calby-pulse.mp3` — Calby Pulse (Dual pulse chime)
- `calby-glass.mp3` — Calby Glass (Crisp glass ping)
- `calby-warm.mp3`  — Calby Warm (Warm acoustic tone)

## Licensing Requirements
Only place audio files here if their license explicitly permits redistribution within a desktop application.
If an audio file is absent or cannot be loaded, Calby automatically falls back to built-in procedural Web Audio tones.
